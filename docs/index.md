建议先阅读仓库根 `README.md`，再按下面顺序进入当前正式文档：

4. `plan/history_plan.md`
   已完成计划的统一归档入口。

## 目录说明

- `background/`
  项目背景与路线原因。
- `design/`
  长期有效的产品设计、结构边界和契约。
- `plan/`
  活跃计划、计划模板和已完成计划归档。当前暂无独立活跃计划，最近完成项见 `plan/history_plan.md`。
- `status/`
  当前状态、风险、少量关键历史节点和下一步。

## 维护约束

- `index.md` 只做导航，不重复维护状态正文。
- 新增、重命名或删除正式文档后，必须同步更新本文件。
- 已完成计划统一归档到 `plan/history_plan.md`，不在 `index.md` 长期维护逐条完成流水账。
